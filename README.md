Landing bilíngue (PT/EN) com tema cósmico/dourado, explicando o pipeline de dublagem local (Qwen2.5-VL + Chatterbox) das 135 cartas de Astral Forge.

## Rodar localmente

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # produção
```

## Stack

Next.js 14 (App Router) · React 18 · TypeScript · Tailwind CSS · i18n client-side · Google Analytics 4.
